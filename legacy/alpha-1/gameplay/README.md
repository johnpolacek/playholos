# Gameplay exploration 001

Open `gameplay.html` directly in a modern browser. All styles and interactions are included in the HTML; the accompanying image is in `assets/awakened-world.png`. No installation, server, or network access is required. Share this directory together to preserve the artwork. Links back to the atlas and concept records require the original repository layout.

This is an illustrated write-up of the September 2026 gameplay discussion, not a game implementation or a new set of agreed mechanics. Its seven chapters cover awakening, investigating a lead, transmission, first contact, an autonomous probe, offline guidance, and overlapping commitments.

The controls change examples within the page:

- Civilization priority changes illustrative allocations of discretionary project capacity.
- Separation and the exchange slider illustrate a light-speed message and immediate reply.
- Probe speed and the shared separation determine idealized arrival and report times.
- Response choices show different diplomatic considerations.
- Time away and guidance select a prewritten illustrative return briefing. No AI service is invoked.

Calculations use 5 real minutes per game year, fixed endpoints, and the shared game reference frame. Probe travel assumes constant cruise speed, omitting development, acceleration, deceleration, and other engineering requirements. The written narrative and final activity chart retain their labeled 20-light-year, 0.1c example even when calculator controls are changed. All sites, messages, project allocations, and events are illustrative.

`assets/awakened-world.png` is original generated concept art made for this page on September 8, 2026: a speculative inhabited terrestrial world at orbital dawn. It is not an observation of a real exoplanet. The page supplies this qualification beside the image and in its assumptions.
